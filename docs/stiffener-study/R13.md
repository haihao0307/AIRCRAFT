# R13 · 钉排背后，是什么？

用户认可 R12 并提供三张照片后，继续研究“外侧钉排是否必然代表蒙皮搭缝”。独立小样使用一块连续蒙皮、一根有凸缘/圆角/腹板的加强件及三根贯穿铆钉。外侧、内侧、轴线剖面和拆层显示同一个连接。

新增的知识是连接对象的区分：钉排可以连接加强件，因此不能只凭外侧钉排添加蒙皮缝。角形加强件为教学实例，不是三张照片或 B-24 的截面测量复原。原图无可靠标尺，没有生成假毫米测量。图 3 已对应摄影者 A72-176 修复图集中的 028 左侧下颌细部；图 1、2 档案身份仍未确认。

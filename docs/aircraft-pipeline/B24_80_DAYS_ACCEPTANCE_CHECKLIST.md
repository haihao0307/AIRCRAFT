# B-24J-25-CO “80 DAYS” acceptance checklist

## 1. Identity and source

- [ ] Aircraft identity reads B-24J-25-CO, serial `42-73257`, aircraft number `487`.
- [ ] Unit reads 308th Bomb Group, 374th Bomb Squadron, Fourteenth Air Force, China, 1944.
- [ ] The authoritative source-model hash and inventory gate passed.
- [ ] No alternate aircraft model or geometry substitution is present.
- [ ] The release records its primary and supporting historical photographs.
- [ ] A single `mission_state_id` is declared.

## 2. Geometry preservation

- [ ] Aircraft silhouette and proportions are unchanged.
- [ ] Greenhouse cockpit, nose glazing, turret openings, tail, wing and fuselage relationships remain source-authentic.
- [ ] Original node hierarchy, animation, mechanisms and original UV remain intact.
- [ ] Displacement does not affect silhouette or mechanical clearance.

## 3. Scope

- [ ] Only approved fuselage exterior and fixed vertical-fin paint surfaces use this livery package.
- [ ] Propellers and hubs retain their existing texture system.
- [ ] Engines and engine internals retain their existing texture system.
- [ ] Wheels, tires and landing gear retain their existing texture system.
- [ ] Glass, guns, turret interiors, cockpit and interior are excluded.
- [ ] Wings, nacelles and horizontal-tail livery are unchanged in the current package.

## 4. Port-side markings

- [ ] Port shark mouth follows port photographs and is not mirrored from starboard.
- [ ] `“80 DAYS”` is white, hand-painted and includes quotation marks.
- [ ] Two port dice are below the title with correct side-specific perspective and pips.
- [ ] `ROBBY` is at the photographed forward location.
- [ ] Port `HUFF` matches E04.
- [ ] `STAM` is absent from port.
- [ ] Port victory flags and bomb marks match the selected mission state.

## 5. Starboard-side markings

- [ ] Starboard shark mouth follows starboard photographs and is not mirrored from port.
- [ ] `“80 DAYS”` and the two starboard dice match E01/E02/E03.

## 6. Symbol meaning and count

- [ ] Japanese victory flags are colored.
- [ ] One victory flag represents one credited Japanese aircraft destroyed.

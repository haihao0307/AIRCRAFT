## Lock meaning

The GLB is the immutable reference sample for appearance, hierarchy, measurements, materials and motion. A file that fails byte count, SHA-256 or inventory validation is rejected before extraction or comparison.

The data-native master may reproduce and later improve individual systems. Every replacement must pass all of the following:

1. Full source extraction and provenance.
2. Manual aircraft-system mapping.
3. Exact reference replay before replacement.
4. Fixed-camera visual comparison.
5. Fixed-time animation comparison.
6. Source-node and native-component mapping.
7. Upstream and user review.

The reference sample remains available during replacement. No guessed or unrelated B24 asset may enter the comparison path.

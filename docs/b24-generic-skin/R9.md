# R9 涂装候选：发动机罩与起落架

用户提供的两张 B-17 Memphis Belle 照片用于本轮发动机罩分色画法试验。参考身份明确为 B-17；B-24 的整机结构、原始几何、原参考军徽位置、发动机内部颜色与 R8 弹舱静态闭合姿态继续保留。两张输入照片的文件名和 SHA-256 记录在 r9-photo-reference.json，照片本身不进入 runtime。

照片的侧面与斜前方视角共同显示：发动机罩前缘的橄榄色包过下唇，下侧灰色主要从其后方展开。R8 在前缘沿发动机轴线高低分色，造成半圈灰色唇口与照片所示画法不符。本轮将前缘橄榄色环绕连续化，并将罩体下侧分界降低、向后柔和过渡；内唇也随前缘连续过渡，四个发动机统一使用 +Z 为前方的源坐标进行检查。这里检查的是空间着色方向，原 UV 仍未恢复。

这是一项按用户指定照片进行的视觉涂装试验，不证明该 B-17 方案是目标 B-24 批次的历史标准。OD/NG 工作色继续沿用此前 B-24 参考，照片用于分色形状和边缘关系；博物馆暖色灯光不作为原漆实测值。发动机缸体、机匣、排气、桨叶厂徽和活塞杆原有材质值保留。

“架子”本轮按起落架处理。支柱外壳调整为较沉稳的中性灰，轮毂单独采用金属材质，抛光活塞杆继续保留独立反射。沿用 [B-24 起落架实机参考](https://www.largescaleplanes.com/walkaround/images/122/122-14.jpg) 的材质类别区分。轮胎调整为稍浅的灰黑橡胶，并用弱幅度程序变化表现轻微浮尘；没有新增磨损几何、UV 或图像贴图。

新增发动机右侧与整流罩侧面检查按钮。tools/qa-b24-r9.py 延续原载荷、60 块弹舱、侧缘/底部覆盖、军徽锁定和视角检查，并对照 R8 已确认的发动机材质。截图使用 Chrome/SwiftShader，结果用于静态涂装审查，不代表实体手机性能或最终历史涂装验收。

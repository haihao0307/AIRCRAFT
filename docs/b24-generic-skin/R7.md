# R7 review candidate

R7 keeps the complete V018 aircraft and replaces the R6 paint classifier and four marking placements. The upper/lower wing classification uses numeric surface envelopes, separate control-surface envelopes, and measured engine axes. Side camouflage follows independent reference profiles. Markings retain their reference positions, including across the closed waist doors and frames. Side markings are evaluated directly on the inherited paint materials so raised frames cannot create projection-grid holes.

The supplied B24_LIVERY_DATA_BAY_FIXED_R1_2026-09-07 package was authorized for integration on 2026-09-07. Its 60 corrected closed matrices are applied once to existing source nodes before painting. The full model payload is retained, with SHA-256 f5ff859a7ff0e38112fa099d8c7d3a4cd8e859434701fb4dd9d81629374c5e3e. Package ZIP SHA-256: e1c7d4378e5dbad84f89f78ae9f257d5cf810cc726275b7bdca84d7f3389d24a. All 11 manifest files and 347 subset geometry buffers were independently hash-checked at intake. The subset does not replace the complete aircraft.

## Reference limits

Four local WebP references recovered from B24_Panel_Seams_Reference_R1.html are hashed in r7-reference-anchors.json. They show Airfix A09011 B-24D artwork; their applicability to the inherited target variant and original JPEG identity remain unverified. Placement backprojection metrics check mapping consistency, not historical truth or independent visual acceptance.

The seam layer contains 105 reference-visible fragments extracted from that HTML's viewData.svg / panel_seam group: 41 top, 39 bottom, 12 port, 13 starboard. Numeric paths retain source IDs and pixel coordinates in runtime/b24-r7-seams.js. Selection is limited to main-wing and aft-fuselage regions, excluding instruction insets, nose artwork and most labels. No gaps are filled and no opposite-side paths are mirrored. Surface mapping uses local body sections and approximate measured wing silhouette anchors; line width and opacity are display choices, not manufacturing dimensions. These are incomplete visual candidates, not an approved complete panel map.

No rivet rows have been invented. Current references and the new bay package contain no resolved rivet positions or pitch. Rivets remain pending source data; this task is not fully visually accepted or production-ready.

## Validation

Run tools/qa-b24-r7.py against the served R7 page. It checks the complete model inventory and payload hash, all 60 bay matrices against supplied endpoints, four marking mappings/orientations, screenshot pixel changes for marking and seam visibility, six cameras, loading, controls and desktop/mobile viewport layout. Chrome SwiftShader is a software-rendering check, not physical mobile/GPU performance validation. Fresh screenshots and qa.json are stored together and report the tested commit and source hashes.

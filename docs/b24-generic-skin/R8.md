# R8：弹舱侧缘闭合与细节材质

R8 修正用户指出的弹舱仍像打开、发动机罩下半部错色、发动机内部涂装不清楚等问题。四处国籍标志沿用 R7 的锚点、尺寸、朝向和表面采样结果。保留完整 V018 的 348 个网格、1784 个节点和原始数值载荷；没有替换整机、修改顶点、法线、索引或恢复旧 UV/图片。

## 弹舱问题及修正

R7 确实应用了交接包的 60 个关闭端点，但该包主要修复门板中缝及相邻板接触，外缘仍沿用原姿态。检查底部射线会命中门板或中央梁，不能证明侧缘也闭合。R8 从两侧检查发现门板外缘与机身侧壁之间仍有约 0.1 米量级的开口，近景可直接看到内部结构。

本轮在既有关闭姿态上，对前后、左右四组卷帘分别作刚性整体旋转和横向平移。外缘接入源机身侧壁；内缘搭接源节点 1714 的中央梁。组内板间关系不变，没有拉伸门板、增加遮缝面或改写几何。旋转约 6.59–7.10 度、横移约 89–100 毫米是当前源模型的静态适配量，不是历史机构参数。拟合设置为侧壁内侧 10 毫米、上方 8 毫米的可视搭接，不能解释为制造公差或机械行程。

`runtime/b24-r8-bay-poses.js` 保存完整静态端点及四组修正来源。`tools/fit-b24-r8-bay.py --source <交接包/data目录>` 可重新生成；依赖 NumPy/SciPy，可用 `--plot <PNG路径>` 输出截面检查图。源子集 geometry.bin SHA-256 为 `84d0eaf16e790989145605c3cd70de1fea64e1f62a58acfafb5455c0876e2e44`，脚本先校验该值。源包只用于离线拟合，不进入网页。

这些端点仅用于本页静态关闭展示。原动画运行器没有接入此修正；不能宣称已完成卷帘运动重建。

## 材质修正

旧的 `airframe-skin` 语义标签也覆盖轮胎、发动机内部和若干起落架零件。R7 的统一染色覆盖了原先按部件选择的材质。R8 在创建蒙皮前排除这些零件，重新制作显示材质：轮胎为低反光深炭黑，机匣为蓝灰、气缸为较暗金属，排气与涡轮部件为暗褐金属，支柱及轮毂为灰色，主支柱独立圆柱节点 630/1217 为较光滑金属。

发动机罩的空间分色扩大至完整罩片范围，避免旧包络遗漏下方罩片而出现矩形错色。薄壁罩的可见内侧采用暗灰色；共用大网格中的桨毂小盖在局部轴线范围内单独分色。新增金属材质另用程序生成的中性反射缓存，避免高金属度活塞杆在缺乏环境反射时变黑；该反射不施加到既有机身蒙皮。它们都是材质/着色器选择，没有旧 UV、旧图像或新的贴板几何。

同时隐藏静态页面中重复显示的轮胎运动模糊替代件。轮胎几何仍在原载荷内。12 片静态桨叶使用较哑光的黑色，保留既有黄尖范围，并加入简化的 Hamilton Standard 厂徽候选。桨叶标记使用新生成的 256×384 canvas 缓存和局部位置投影；不写入源 UV，也不复制照片中的具体桨叶编号。该缓存与现有军徽/数值包络纹理一样，需要 GPU 纹理对象，不能描述成零纹理。

## 实机细节研究（2026-09-08）

主要依据为摄影者 Tim Valdez 的 [B-24 实机 walkaround](https://www.largescaleplanes.com/walkaround/wk.php?wid=122)（2013）。这是修复机的直接照片，适合判断材质类别和可见构造；不能直接证明本模型所代表批次、历史时点的全部颜色及零件编号。照片未打包进 runtime，也未以新纹理导入。

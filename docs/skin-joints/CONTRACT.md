# R14 蒙皮连接模块合同

本轮交付可复用的金属蒙皮连接数据与两种显示：有真实孔和板厚的结构工作台、B-24 曲面外观集成。仅用于可视化，不输出制造或维修参数。

- 接头拥有独立身份、连接对象、接头类型、钉头类型、尺寸单位、路径与证据级别。钉排由路径弧长生成；活动边界不自动生成铆钉。
- 结构小样覆盖搭接、衬板对接、加强件连接；凸头与埋头可切换。埋头展示厚板切削窝，薄板压窝暂未实现，不能互相冒充。
- 小样参数为选定示例：D=3.175 mm、板厚2 mm、100度锥角、1 mm埋深；镦头示意直径1.5D、高度0.5D。相邻孔、板边和连接区检查失败时拒绝生成。
- B-24 只在后机身选一块非活动曲面做示意集成；局部坐标、板界、钉距未完成制造资料校准。修复机照片只支持存在板界/钉排这一观察，不支持所选示意坐标。整机层只显示外侧钉头和接缝，不伪称已切穿原机壳或重建内骨架。
- 所有原始 position/normal/index 数组保持；作废旧105段和R11未校准候选均不导入。实例可以替换，不要求所有飞机使用同一种接头、材料或钉距。
- 目标：工作台小于100k三角形/35 draws；整机新增低于20k三角形/8 draws，使用实例化和距离隐藏；无原始位图、UV或GLB依赖。WebGL失败提供文字提示，隐藏页面暂停绘制，释放重建资源。
- 发布使用新提交固定公网 HTTPS，实际浏览器检查版本、核心操作、资源一致性与源数据审计；旧版本不改。

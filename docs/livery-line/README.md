# 独立历史涂装生产线

## 定位

飞机生产线现在分成两条长期并行的直线。

第一条负责飞机本体，包括几何、机构、动画、飞行、炮塔、起落架和渲染运行时。

第二条负责历史涂装，包括飞机身份、部队编制、机组、人物、事件、照片证据、任务时态、图形复原、PBR 贴图、可编辑蒙版、审核记录和最终导出包。

两条线通过单向导入连接。涂装线不会读取或写入任何飞机二进制文件，也不会保存渲染节点名、几何信息、目标材质槽或目标纹理坐标。飞机本体在消费涂装包时提供外部绑定适配器。

## 为什么这样拆分

一架历史飞机的资料会长期增长。机组成员、地勤人员、拍摄地点、任务、事故、照片时间、机鼻绘、任务标记和旧化状态都可能逐步补全。把这些信息绑在某一个具体网页或某一个具体三维资产上，会让资料随着实现变更而重复制作。

独立涂装记录以历史对象为中心。只要飞机身份不变，更换网页、渲染器或三维资产都不会改变历史档案与已批准的涂装素材。

## 十段直线流程

1. 飞机身份：型号、批次、序列号、机号、名称。
2. 部队编制：航空队、轰炸大队、轰炸中队、战区与服役时期。
3. 机组与人物：机组编号、岗位、人员、地勤、照片人物、机身姓名标记。
4. 事件与任务：任务、转场、损伤、修理、事故、拍摄、涂装变化。
5. 照片与证据：原始照片、档案号、来源、视角、时间、可信度、派生裁切。
6. 涂装复原：左右舷独立图形、编号、单位标志、机鼻绘、字体、色彩与旧化。
7. 时态冻结：选择一个可证明的时间状态，冻结任务标记和胜利标记数量。
8. 贴图与蒙版：Base Color、Normal、Roughness、Height、可选 AO 与 Metallic，以及可编辑标记和旧化蒙版。
9. 历史验收：逐项核对来源、位置、数量、左右差异、色彩推断和未知项。
10. 独立包导出：形成带完整谱系和校验和的可移植涂装包。

## 数据组织

```text
data/livery-line/
  catalog.json
  package-template.json
  records/
    308bg-374bs-42-73257-80-days.json
    308bg-374bs-42-73436-ubangi-bag-iii.json
```

每个记录完整包含以下九类信息：

```text
identity
organization
crew
events
evidence
livery
export
```

人员姓名与机身文字必须分开。照片上出现 `ROBBY`、`HUFF` 或 `STAM` 时，可以先记录为姓名标记。只有找到可验证的人员身份资料后，才能把文字链接到真实人物。

```text
<livery-id>-<version>/
  manifest.json
  identity.json
  organization.json
  crew.json

  evidence.json
  markings.json
  mission-state.json
  provenance.json
  decals/

    base-color.*
    normal.*
    roughness.*
    height.*
    ambient-occlusion.*
    metallic.*
  masks/
    markings/
    weathering/
  previews/
  checksums.sha256
```

没有通过历史验收、任务时态验收和贴图验收的记录不得生成可用成品包。缺失项必须明确标记为待研究、待计数、待色彩确认或待批准。

## 与飞机本体的连接

涂装包使用标准化的飞机家族语义表面名称和独立图形锚点，例如前机身左侧、前机身右侧、任务标记区域和固定垂尾。飞机本体负责把这些语义区域绑定到自己的表面实现。

绑定适配器属于飞机本体生产线，不进入历史涂装包。这样可以让同一套历史涂装资产被不同的合格 B-24 实现消费，同时保持历史信息、人物关系、事件时间线和图形资产只有一个权威版本。

## 现有两架飞机

`“80 DAYS”` 已建立较完整的证据和任务时态入口。机组实名与事件时间线仍需继续研究，炸弹任务标记仍需经可复核标注计数。

`UBANGI BAG III` 的飞机身份和部队编制已经锁定。现有 V1 图形只承担流程测试，完整历史照片清单、机组、事件和 V2 涂装仍需补充。

## 强制规则

不得根据机身姓名标记猜测完整人员身份。

不得把不同时间照片中的任务标记合并成一个虚构状态。

不得把生成图当作历史证据。

不得在涂装数据中写入目标三维资产、表面层级、节点名、几何、动画、材质槽或目标纹理坐标。

不得让飞机本体修改历史档案。所有资料修订必须回到涂装生产线，经过证据记录和版本化审批。

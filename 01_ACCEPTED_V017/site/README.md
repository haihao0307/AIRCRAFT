# UBANGI BAG III 第一版测试网站

本目录是可直接发布到 GitHub Pages 的独立检查站。

当前涂装板只用于跑通以下链路：

1. 权威 B-24 GLB 的读取与 SHA-256 校验。
2. 旧版内置 HTML 中 GLB 的自动提取。
3. 浏览器 IndexedDB 模型缓存。
4. 真实模型网格分类。
5. 固定外蒙皮与机械零件分离。
6. 第一版机鼻图案与尾号的运行时投影校准。
7. 原始材质、测试涂装、分类审计三种查看模式。
8. 多角度、近景、动画和分类报告检查。

下一版正确涂装图片到位后，保持模型、资产锁、分类和网站结构，只替换涂装参考与最终 PBR 资产。

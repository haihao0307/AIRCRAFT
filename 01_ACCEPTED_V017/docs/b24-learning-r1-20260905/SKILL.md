## 3. 材质与照明：先分类，再做受控比较

来源原理：小妈资源地图 R13 要求中性、掠射和生产照明对照；R14 提醒相机、照明和材质可能共同影响外观。PBRT 9.6 用微表面统计描述粗糙度对反射分布的影响。这些内容没有提供 B24 专属风化参数，也不能证明某张截图的参数唯一正确。

本线源码证据：`NativeAircraft.material()` 已分别处理轮胎、玻璃、螺旋桨、起落架、内部机械和蒙皮。轮胎索引集合在当前锁定来源中为 `[598,613,1189,1200,681,689,698]`。这些编号只在该资产版本内有效。`skinMaterials` 的收集发生于相应条件分支之后，不能把所有 Mesh 一起当作外壳蒙皮。

本线操作合同：输入为固定资产身份、sourceNode、semanticFamily、部件路径、原材料参数、原 UV、相机和光照状态；输出为独立候选材料参数与选择范围报告。范围内可试验颜色、粗糙度和表面遮罩，原节点变换、几何、动画、源 UV 和未授权材料必须保持。

下一项材料试验采用同一块已确认外蒙皮，固定相机、曝光、环境、尺寸和时间，分别查看中性与掠射光。先检查该节点到底走到哪个材质分支，再单独改变一个候选参数。色彩、粗糙度、法线和环境照明分别比较，不能用大幅提亮掩盖错误分类。轮胎泥尘、机械件油污、蒙皮磨损必须保留各自的对象选择和依据，不先给全机覆盖统一磨损。

失败条件：对象身份不明、选择穿过机械隔离边界、参数改变导致原模型或动画变更、只在一张调过曝光的图中改善，或没有相应真实参照。此试验状态为 planned，尚无新材料视觉结果。

## 4. Blender：坐标、属性域和实例共享

来源原理：field 在几何上下文中求值，变换前后的上下文可能不同。实例共享几何与实体复制有不同的修改范围。来源卡要求记录坐标系、属性域和求值时刻。

本线源码证据：`minY()` 使用顶点与 `mesh.matrixWorld` 求接地高度；节点保留来源的局部变换和父子关系；多个节点可能使用同一个几何对象。因此不能拿局部坐标直接比较世界地面，也不能为修一个部件而修改共享几何后默认其他实例不受影响。

本线合同：输入为来源节点、局部顶点/法线、父链、矩阵、动画采样状态及单位；输出为明确标注空间的测量结果和依赖列表。先记录 local 与 world 两套量，再解释差异。材质遮罩所使用的坐标空间必须明确。原 UV 保持；任何 LiveryUV 或拆分共享顶点的工作需要单独进入既有涂装批准流程。

改变前提的预测：飞机整体平移后，局部空间定义的表面图案应继续跟随同一部件；固定世界坐标中的图案会出现不同采样。这个预测只用于后续遮罩设计，没有证据说明当前网页已经发生该问题。局部到世界的法线处理还需考虑非均匀缩放，不能用一张渲染图替代数值检查。

计划检查两个不同变换的合法测试对象，并比较保留实例与实体化后的数据和成本。Blender 实机、导出往返、真实轮组修正均为 not_run。不得用统一 Apply Transform、重做骨架或重采样原动画来消除尚未定位的显示问题。

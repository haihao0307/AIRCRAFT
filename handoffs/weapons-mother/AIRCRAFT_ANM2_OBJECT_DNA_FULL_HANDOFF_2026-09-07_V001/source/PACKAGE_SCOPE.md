# 包范围与排除项

## 包含

构建流程会从冻结提交复制以下内容：

1. `production/aircraft-anm2/` 全目录
2. 本交接目录的 `source/` 文件
3. 与本线直接相关的 GitHub Actions 工作流
4. 当前源提交、分支和提交历史记录
5. 逐文件 SHA-256 清单
6. ZIP 校验记录
7. W02 至 W08 的源码、记录与已存在的单文件 HTML
8. W08 退回文档、当前状态和失败账本
9. Object DNA 与 World Kernel 交接位置
10. 研究工具组合及已保存的实际探针结果

## 允许保留的图像

仓库中已有的 QA、审查或研究图像可以进入包，必须继续保持 evidence 身份。它们不能作为产品贴图输入。用户在 2026-09-07 提交的 W08 两张截图所揭示的问题，已经完整转写进 `FAILURE_LEDGER.md` 和 W08 退回文档。聊天附件本身不作为 GitHub 产品资产写入。

## 明确排除

1. 参考 GLB
2. 辅助弹药 GLB
3. Blender、Chromium 和 Python 工具链二进制包
4. 字体文件
5. 外部库安装缓存
6. Git 凭据与连接信息
7. 浏览器缓存
8. 原始顶点、索引与 UV 的独立导出表
9. 参考 mesh 的改名、压缩、Base64 或其他编码副本
10. 未授权的 B17 生产扩展

## 参考输入恢复方法

新生产线需要原件时，使用用户已有的本地文件：

`anm2_browning_.50_cal_aircraft_machine_gun(1).glb`

必须同时核验：

`bytes = 6548040`

`sha256 = 2d6a1f323018523db42d1fe54dcf1a26661f139548134835779933d61ab68c8b`

## 包的含义

本包提供完整可恢复的知识、源码、失败历史、审查页面和重启约束。它不代表任何旧工作台获得视觉接受，也不提供现实武器制造、优化或操作资料。

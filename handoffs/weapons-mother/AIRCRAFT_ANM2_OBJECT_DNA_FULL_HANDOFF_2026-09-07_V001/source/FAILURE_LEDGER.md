# 失败账本

本文件必须随生产线长期保存。失败对照用于阻止旧错误重新进入新线，不代表需要继续修补旧实现。

## F001：S01 旧链路污染

状态：永久退出生产

主要问题：

1. 方向与九十度旋转补丁长期漂移。
2. 旧切件、旧场景与旧依赖相互缠绕。
3. 供弹、支架、瞄具和动画关系缺少可靠证据。
4. 后续修补越来越依赖旧错误。

处理：删除生产入口，历史记录可保留，禁止复活。

## F002：R01 原生外观质量过低

状态：用户否决

主要问题：

1. 外形概括过度，无法达到精细机械资产标准。
2. 部件关系、支架、供弹与瞄具只形成粗略候选。
3. 功能数量和测试数量被放在了视觉质量前面。

处理：退出生产，只作失败参考。

## F003：W02 只完成原件查看

状态：有效参考工具，不能当作独立复制

有效部分：

1. 严格核验原件大小与 SHA-256。
2. 读取 28 节点、13 网格、51 访问器。
3. 保留父子关系与节点矩阵。
4. 本地只读载入，不上传和持久缓存。

限制：

1. 没有独立 GeometryProgram。
2. 没有完成 B24 安装层。
3. 没有完成年代材质和动画。

## F004：W03 与 W04 只完成侧板局部

状态：局部研究，不能作为整枪基线

有效部分：

1. 开始把侧板轮廓、孔、分层和头部形态写成规则。
2. W04 撤回了缺少依据的整片背板。
3. 修正了部分反向头部法线。

限制：

1. 厚度、可见边壁和隐藏结构仍未完全核实。
2. 整枪部件、功能开口和 B24 外接系统缺失。
3. 侧板局部成功不能外推到完整机械资产。

## F005：W05 材质扩展早于整枪准确

状态：材质方法可研究，形态没有推进

主要问题：

1. 增加多种旧化与 PBR 控制，几何没有同步提升。
2. 容易让画面质感掩盖背面、厚度和部件缺失。
3. 历史材料标定仍未完成。

处理：保留 cause-based material 的思想，禁止把 W05 视觉结果当成历史材质真值。

## F006：W06 整枪候选的形态与完整性失败

状态：用户认为质感较好，几何不合格

肉眼可见问题：

1. 枪管后段与机匣连接断裂。
2. 默认透视产生明显畸变。
3. 机匣过于方正和简单。
4. 供弹入口、排出开口、瞄具缺失。
5. 弹药箱、弹链、支架和 B24 安装关系被拿掉。
6. 后部握持、控制件、顶盖与板层关系简化严重。

根因：先完成程序化外观与质感，再补机械语义与结构；顺序错误。

处理：PBR 方法可以拆解研究，W06 整体几何禁止成为新基线。

## F007：W07 改善审查方式，注册仍然错误

状态：生产方法的部分成果，几何与注册不合格

有效部分：

1. Reference Twin 和 Native Twin 并排常驻。
2. 原件只读载入。
3. 默认使用正交审查，减少透视误导。
4. 功能缺口在界面中公开显示。
5. 固定提交单文件 HTML 与 raw.githack 交付格式成立。

失败部分：

1. 参考体按总长度缩放，再按包围盒中心平移。
2. 没有使用枪管轴、枪口面、机匣前后面与顶面注册。
3. W07 仍沿用 W06 生成几何。

处理：保留双对象工作方式和交付方式，删除注册算法和旧几何依赖。

## F008：W08 测量方法与交付流程失败

状态：正式退回，当前最关键失败

固定失败版本：`7095e8da44b2a9b589913718d0d1c01adb72615e`

用户实际加载原件后的截图显示：

1. 机匣垂直位置、枪管中心线、前端过渡和后端范围没有对齐。
2. Native 机匣仍是简化长方体，参考体的大量层次和控制件缺失。
3. 枪管根部、前环、外露管段、护套起点、直径、长度、孔洞和前端结束结构均有明显差异。
4. 青色半透明参考体覆盖黑色 Native，叠合方式掩盖错误。
5. 图表显示平均误差约 `0.0103`、最大约 `0.0407`，与肉眼巨大差异冲突。

测量算法错误：

1. 两个对象在各自包围盒里独立归一化，所取 `t` 不代表同一机械位置。
2. 每个截面只保存 Y/Z 最小值和最大值。
3. 丢失轮廓中心、面积、周长、环数、孔洞、方向、部件身份和有符号偏移。
4. 整枪平均值被长而细的枪管区域主导，机匣局部大误差被稀释。
5. 缺少语义区域权重、必备部件门槛和失败阈值。
6. CI 只验证了未加载原件的单文件运行。
7. 发布前没有完成真实原件载入后的人工预检。

处理：

1. W08 只保留为失败历史。
2. `measurementKernelAccepted=false`。
3. `geometryParityAccepted=false`。
4. 当前没有用户候选。
5. 新测量必须按共享机械基准和语义区域重做。

## F009：流程层失败

状态：必须永久记住

失败行为：理论文档、图表、按钮和自动测试掩盖了几何没有进步的事实。用户成为首个真实参考载入后的视觉 QA。

新规则：

1. 用户不能再成为第一位真实参考视觉检查者。
2. 页面功能增长不能替代模型收敛。
3. 没有加载原件的测试只能证明页面可运行。
4. 自动化成功不能提升历史准确、几何一致性或人工接受状态。
5. 下一版没有明确可见改进时，不生成对外链接。

# 第二步：统一坐标、分件和展示状态

本轮读取基线：4899b4c295fdb98ccb821c470a35a4ca2c04991a。只沿 native/weapons-visual 规则生成目录执行，S01 保持删除，不读取其场景或混合网格作为生产输入。

已实现 core/inspection.py：不可变语义部件图、绝对展开/复位、隐藏与单件观察规则、材质状态隔离、保存/恢复校验，以及暂停、慢放、拖动进度、重播和有限容量的视觉事件轨。每五个事件一个强调标记，为用户指定的曳光显示预设提供节奏语义；尚未渲染曳光、弹壳或供弹动画，不引入真实武器操作/性能数据。

新生成器约定 X 为前方、Y 为上方、Z 保持右手系。Blender 端统一通过 (x,-z,y) 的适配变换。根节点不再接受额外旋转或位移补丁。这个数学约定只保证实现一致性，不能证明尚未生成的 Aircraft 外观方向已通过历史参照和人工审查。

分件观察进入展开状态时暂停演示，复位后不自动启动。所有姿态从记录的初始关系计算。选择子件时保留父级变换的作用，隐藏祖先则一并隐藏子件。材质参数只改相应表面状态，不改部件图。不同生成规则或不同部件关系的保存记录不能混入；无效记录先拒绝，不能只应用其中一半。当前状态接口要求单一写入者，没有浏览器或任意外部渲染器事务保证。

新增 test_inspection.py 的 63 项本地测试已通过；包含前轮19项，共82项。tools/inspection_probe.py 用新状态层驱动 Blender 中的临时中性试片，真实远端执行结果须以本轮 Actions 回执为准。试片不会作为枪体或工作台交付，未使用参考网格和图片。

本轮外部资料核验：Smithsonian A19680511000 与 AWM REL26872 的官方检索正文有助于确认航空外观参考范围；Smithsonian 图像检索出现其穿孔护套照片。本轮相关馆藏正文直读出现403、429或缓存失败，不能宣称已完成完整图库审阅。没有据不完整的图像拼造完整枪体，也没有新增任何历史尺寸/内部机构的判断。

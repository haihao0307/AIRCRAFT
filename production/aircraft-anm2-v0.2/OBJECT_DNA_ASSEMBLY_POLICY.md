# Object DNA 组成与相对位置合同

用户要求：2026-09-08。每个有独立实体语义的对象形成自己的 Object DNA；按照参考坐标核对相对位置；弹药与供给相关对象纳入整体考虑。

## 对象记录

每个实体部件记录自身 ID、类型、DNA 规则版本、组成角色、局部参考架、几何规则引用、材料域、状态、历史与证据。区域记录宿主及边界，不因独立网格而升级为实体。

共享类型规则与具体实例分开。重复对象可引用同一模板，但各自保留实例身份及位姿。记录当前姿态不等于已知历史姿态。

## 关系与坐标

- 类型继承、有效期内的组成关系、位姿父链分别保存。
- 每个局部参考架声明轴向、单位或未标定状态、基准来源及版本。
- 相对位姿连接到明确父参考架；锚点对应和空间关系须有可追溯依据。未验证的连接只作候选。
- 所有相关对象读取同一配置、时间和知识快照。父参考架变化时，子对象位置一致更新。
- 未知变换不填零位移或单位旋转。缺少世界锚定时保留局部关系，不宣称已知地理位置。
- 通过固定同尺度视图核对位置、轴向、连接处与不合理穿插；视觉看齐不等于历史配置或实际安装已验证。
- 展示爆炸图使用独立显示偏移，保留总装位姿；显示偏移不是实际拆卸路径。

# 两份新增参考的蒸馏研究 — 2026-09-08

本轮仅检查文件、渲染原材质、隔离对象并形成研究结论。没有修改 W11，没有将参考网格或纹理写入生成规则，没有删除源文件。临时查看器只经本地 File API 读取原件，未上传；此文档不是网页预览交付。

## 1. 弹药参考：可分离，但不是 M2 的尺寸参考

文件：`G:/飞虎队十四航空队/各种机型/B-24_CBI/M2  ammo_7.62_x_54mmr.glb`。

文件名添加的 M2 前缀与文件内部身份不一致。内嵌原作者标题为 Ammo 7.62 x 54mmR，作者 Pedro Belthori，材料名也为 7.62x54mm_Mat。原作者页面同样确认这个名称：https://sketchfab.com/3d-models/ammo-762-x-54mmr-d097387f41cc483fa1bd9b0296ebcf90 。Browning .50 M2 的弹药类别为 12.7×99；参照制造商说明 https://fnherstal.com/en/addressing-future-battlefield-requirements-with-fn-herstal-machine-guns/ 。因此不能以改名或整体缩放将这份 7.62×54mmR 外形认定为 M2 弹药。

实际检查：15 节点、6 网格、2256 三角形、1 材质、3 张 1024×1024 内嵌 PNG；无动画、无蒙皮、无形变目标。3 个 Cartridge 对象与 3 个 Projectile 对象已经分别存在，名称和单独渲染均证实弹壳/弹头分离；不是只靠颜色区别。场景摆放中有装合状态，也有分开放置状态；这些是静态摆放，不是动画帧。

可吸收：弹头/弹壳作为独立对象的语义；装合与分离展示保留身份的方法；铜色与黄铜色的材质分区、细微表面变化；壳口作为开口外观的表达。不能直接采纳：7.62×54mmR 的比例、外缘、标识、弹尖配色以及其数字坐标作为航空 M2 的尺寸真值。近景能看到低多边形轮廓；壳网格焊接后仍非封闭，不能据双面显示推定已建完整内壁厚度。

正确的 12.7×99 外观还应与现有 `12.7x99mm_m2_ball_still_practice_no_texture.glb` 交叉核验；这次没有将其身份仅凭文件名视为已验收。

## 2. Browning M2：弹箱、弹带和表面细节最有价值

文件：`G:/飞虎队十四航空队/各种机型/B-24_CBI/browning_m2.glb`。

实际检查：17 节点、7 网格、207207 三角形、3 材质、9 张 1024×1024 内嵌图像；无动画、无蒙皮、无形变目标。内嵌作者为 emran.bayati，原题 Browning M2，来源 https://sketchfab.com/3d-models/browning-m2-381c0f1939e843ceae232500e24e7231 。本轮该网页返回 403，文件本身成功读取、渲染；作者/许可依据内嵌元数据。

视觉观察到地面三脚架、圆形展示地台、开盖弹箱、另一个闭合弹箱、箱内排列的弹带、伸出箱体的带状弹药，以及地面散落弹壳和链节。可见开放的枪口外观和前后机械瞄具外观，未见独立光学瞄准镜。该场景支持“地面展示配置”的判断，不能凭模型把其具体版本和年代作为历史定论。

| 项目 | 与 W11 比较 | 采纳条件 |
|---|---|---|
| 弹箱 | 增加箱盖、开口、卷边/折边、压筋、提手、扣件、字样与漆面变化 | 可形成独立箱体候选；与 B24 的历史安装关系另行核验 |

## 3. 动画与对象结构的限制

两份 GLB 的 animation clips、skins、morph targets 均为 0，因此没有现成动画可提取或迁移。第一份弹药已有可单独控制的弹头/弹壳对象。第二份则是静态场景：Main_low001 的两个网格包含枪身及支架外观，box_low002 的两个网格包含开箱、箱盖与弹带，bullet_low094 实际为散落弹壳/链节集合。节点名不是可靠的实体划分。

焊接位置后按面邻接检查，第二份多个网格内存在大量断开的表面片；这些片可帮助后续语义分组，但不能把“连通片”直接叫做“独立零件”。例如箱体外观组两网格共有 203 个表面连通片，其中包含重复实例及分离表面。当前文件没有提供每个实例的独立身份、动画枢轴、父子关系或状态轨道。后续视觉动画需要重新组织这些展示对象，不能声称已有动画已被蒸馏。

## 4. 材质读取与永久知识

两份文件含 base color、metallic/roughness、normal；M2 另有 AO 和一个材质的 KHR_materials_specular。实际检查第二份 UV 存在超出 0..1 的坐标，采样器指定 REPEAT；若错用 CLAMP，会把弹箱和弹药显示成拉伸条纹。修正采样器后重新截图，颜色和表面细节正常。这是材质阅读规则，不能把错误预览归因于原件质量。

原贴图依赖其原 UV，不能直接贴到 W11 的新几何就宣称一致。可保留来源支持的颜色、粗糙度分区、边缘磨损位置和材质变化规则，再在原件对照与多光照下验收。9 张 1K 贴图和 20.7 万三角形是原场景实现方式，不是我们的生产预算或必须继承的结构。

两份文件内嵌许可均标 CC BY 4.0。研究记录保留原作者、来源、哈希与许可字段，后续删除参考副本也不能丢失来源记录。只有完成知识转写、脱离源文件重建以及视觉复核后，才讨论源文件清理；本轮未删除任何参考。

## 5. 本轮结论

优先吸收：弹头/弹壳语义分离；弹箱细部层次；弹带与链节外观；材质分层及正确纹理采样。隔离：异口径尺寸、地面枪架/地台、具体瞄具与航空安装关系。当前这两份文件不能补齐现成动画和 B24 航空支承资料。

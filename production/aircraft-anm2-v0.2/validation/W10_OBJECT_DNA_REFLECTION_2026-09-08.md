# AN/M2 W10：相机、后端差异与完整 Object DNA 反思

2026-09-08。按用户要求先交文字；本轮不改写固定发布的 W10，不把尚未制作的爆炸图称为完成。

当前结论：W10 在可读外形和表面表现上已有进展，但仍是历史外观数字资产候选，尚不是完整的 AN/M2 Object DNA。缺口不仅是架子、瞄具，还包括物理部件划分、功能关系、具体配置、装机归属和证据覆盖。

**原件内容纠正（用户提醒后实际复核）：同一 GLB 已有箱体、弹药及带状供弹外观。下文“未建立”指 Native / Object DNA 未建立，不是原件缺少这些内容。W10 枪体视图把相关节点排除在显示范围之外。见 [原件复核记录](SOURCE_SUPPLY_RECHECK_2026-09-08.md)。**

## 1. 视角为什么不对，如何防止再犯

已核查 `workbench/w10/app.js`：只有 OrthographicCamera，连可旋转的“立体”视图也用正交投影。正交投影不会把远处按距离缩小，沿枪身观察时会产生不自然的纵深感。截图反映了这个问题；但目前没有证据把它叫作真正的反向透视。部件真实外形大小与遮挡也会影响主观判断。

此前将测量相机继续用作立体展示，是实现上的疏漏。已将纠正规则写入 G:/AIRCRAFT/AGENTS.md 和当前生产目录 AGENTS.md：

- 立体展示采用普通透视，近大远小；不允许反向透视、镜像、负尺度补偿。
- 尺寸/轮廓判断使用明确标注的正侧、俯视、前后端固定正交视图。斜向正交只能辅助理解结构。
- 两枪共享基准、投影、姿态、缩放和等比例画布，不各自自动放大到“看起来一样大”。
- 验收检查两个端部、透视/正交切换以及窗口缩放。旧版保留，新版修正。

规则已经写入，W10 页面本身尚未修复。用户这轮要求文字优先，因此不以修改历史入口代替解释。

## 2. 两枪后端对照：哪些是模型差异，哪些仍待历史裁定

对照依据：用户两张同框截图、W10 实际生成规则、已载入真实原件的既有同基准对照，以及本轮历史手册查阅。左侧 GLB 是数字参考，不自动等于原厂真值。

| 位置 | 左侧参考模型 | 右侧 W10 | 当前判断 |
|---|---|---|---|
| 后板上方翼状/V形轮廓 | 有独立、明显的翼状控制件 | 变成顶部框形与中央竖片，正后方读不出同一轮廓 | 明确的生成表达差异；规则使用平面框和竖片作近似，不是已核定的另一型号 |
| 中央圆形突出物 | 端部有多层环状轮廓 | 简化成较平滑的圆端 | 外观近似过度；与后板缓冲组件的归属有关，不能叫成普通装饰圆钮；端面细节尚未裁定 |
| 两侧握把及端盖 | 握把曲线和盖缘有起伏 | 使用简化旋转轮廓，端盖更平 | 已知几何简化；不能仅凭它声称年代差异 |
| 上下连接框、后板边角 | 层次、空隙和圆角有变化 | 框形较规整，边角与遮挡关系不同 | 需要独立后端区域核验，不能靠整体轮廓平均掩盖 |
| 侧面长柄与连接部 | 有自身曲线、盖缘与连接形态 | 采用少量剖面与板状近似 | 对应关系为候选；确切历史配置仍需独立证据 |

原因不是两支模型已经分别代表了两个真实变型。W09 优先修整机匣和根部，后端保留为简化上下文；W10 复制该几何，仅加入材质。现在后端细节被看得更清楚，这些遗留问题必须进入下一轮主检查范围。

### 已查到的历史依据及其界限

1. **1942 年美国陆军部 TM 9-225，第3页**：对象是 .50 口径航空 M2，属于后坐作用、弹带供弹、空气冷却的机械系统。名称中必须保留“航空型”和口径，不能只写 M2。[原始手册第3页](https://digital.library.unt.edu/ark:/67531/metadc29988/m1/5/)
2. **同册第6页**：描述了带双握把、手动控制件的后板，也提到不带这些握把、由安装设备承担相关控制的配置。双握把不是所有航空 M2 的无条件共性。[原始手册第6页](https://digital.library.unt.edu/ark:/67531/metadc29988/m1/8/)
3. **同册第8页**：瞄具被列作飞机设备；其归属和装配位置与配置有关。因此“缺瞄具”应作为枪位系统的待判定项，不能直接补一个通用望远式瞄准镜。[原始手册第8页](https://digital.library.unt.edu/ark:/67531/metadc29988/m1/10/)
4. **1947 年 TM 9-225，第84—86页，尤其图66**：本轮已下载并实际查看扫描图。带握把后板的插图能看到双握把、上方翼状控制件与后向圆筒。这支持左侧参考的总体后端布局，同时暴露右侧控制件表达不足；不证明左侧所有端面、圆角和比例正确。[1947年手册](https://hangarthirteen.org/wp-content/uploads/2021/07/9-225-Technical-Manual-Browning-Machine-Gun-Caliber-50-AN-M2-Aircraft-Basic.pdf#page=88)

**尚未获得与目标 B-24 具体批次、枪位、日期对应的原厂后板图纸及修订号。**以上是当时的官方手册和后期手册插图，不能称为已按原厂制造图逐项校准。1947 年资料也不能无条件回填二战某个历史实例。当前可判定“右侧明显失真”，不能判定“左侧全对”。

## 3. 我的 Object DNA 应当是什么

已向小妈任务发送用户要求的知识索取，并读取她现有的《系统总纲》《对象与领域映射》和 Object DNA Kernel。初稿交付后，小妈的[专门补充答复](G:/小妈/知识体系/会议/2026-09-08_造波与世界体系同步/M2_ObjectDNA_补充答复.md)已返回并完成阅读；以下补入她对分类、关系与验收状态的细化。她没有独立检查 W10，也没有提供新的 AN/M2 历史实物证据。

小妈的要求是：完整对象必须能回答身份、组成、关系、形态、材料、能力、状态、历史、证据和未知。网格不是物理部件，显示分组不是装配树，表面区域也不必是一件可拆零件。

当前身份应这样写：

- **类型**：Browning .50 航空 M2 / AN-M2 家族中的候选配置。
- **数字资产实例**：ODNA:MECH:ANM2:PILOT-0001，生成代 GEN-0002，显示版本 W10。
- **历史实体**：尚未对应到某一支有序列号、服役日期和装机记录的真实枪。数字资产 ID 不能冒充历史实体 ID。
- **当前可见配置**：双握把后端与侧柄外观候选；不能因此宣称适用于全部 B-24 枪位。

每个语义子对象至少要有：稳定 ID、名称、作用、上级组成关系、与其他对象的连接关系、外观证据、材料域、状态/历史和完成度。没有证据的字段保留 unknown；不适用与未知分别记录。

小妈补充了四项必须落实的区分：

1. **类型继承、实体组成、位姿父链是三种关系。**分别记录共享定义、某时段的组成角色、某时刻的位置解释；组成树不能直接充当全部空间与连接关系。
2. **实体部件不必可拆，区域也不因有名字就成为部件。**爆炸图只能是有依据的展示展开，不能用可移动网格反推物理可拆性。
3. **知识、实现、验证分别记状态。**“有资料支持但未实现”“已实现但未核验”“配置未知”“不适用”必须分开；小妈矩阵中的“未核验”不能转写成 W10 缺件。
4. **完整性同时检查目标覆盖与可回读性。**规则能够重建当前模型，不证明目标对象的知识已完整；新版本修正数字表示，也不等于历史实物发生变化。

W10 的7个显示分组、107个网格，只说明渲染组织。当前语义表虽已有候选条目，但仍标注14个必需条目、0个完成验收，不能换算成某个百分比的整枪完成度。

## 4. 子部件与缺项表

这是一张博物馆数字展示层级的完整性检查表，不是原厂零件目录或实际拆装顺序。

表中实现判断来自本任务对 W10 规则、语义表及运行结果的检查，不是小妈出具的资产验收。具体历史配置未知的项目仅标待判定，不能据此断言真实枪位一定具备该项。对展示目标尚未实现的对象也不代表原件 GLB 中必然不存在相关形状。

| 子对象/系统 | 在对象里承担什么角色 | W10 状态 | 下一步需要补什么 |
|---|---|---|---|
| 机匣与外部板件 | 主体结构，组织其他部件与界面 | 外观候选已存在 | 核准名称、板层边界、开口和物理部件划分 |
| 顶盖与供弹区域 | 供弹系统相关结构与外部边界 | 外形存在，内部语义不足 | 将“可见盖板”和“供弹功能”分开记录 |
| 枪管 | 独立语义部件 | 与前部显示组混合，未形成完整独立对象 | 建立枪管自身身份、可见范围与证据边界 |
| 穿孔护套、前端及根部外观 | 包覆/支承相关外观结构 | 已有形态，部分轮廓仍不一致 | 护套不能当作枪管本体；拆分语义与核验范围 |
| 后板、双握把、翼状控制件 | 后部组成与人机控制外观 | 明显简化，局部失真 | 先修控制件、握把端盖、后板层次；保留配置适用条件 |
| 侧面操作件 | 配置相关的人机界面 | 仅外部近似 | 核准历史名称、配置归属及外形 |
| 枪机及相关内部机构 | 高层机械运动与状态关系 | 未建立完整对象 | 先建有证据的语义占位与功能关系，不凭外壳猜内部细节 |
| 复位、缓冲相关组件 | 运动能量与状态恢复相关作用 | 只有部分外观暗示 | 不将后方圆筒等同完整内部系统；明确内外证据差别 |
| 瞄准设备及其支架 | 观察/瞄准关系 | 缺失或适用性未知 | 依枪位资料选择，不能默认是望远式瞄准镜 |
| 枪架、托架、连接支承 | 枪与枪位之间的安装关系 | 未建立 | 先确定具体枪位系统与资料，不拿其他平台架子补空 |
| 弹箱、弹带与弹药外观 | 枪位中的供给相关对象 | 原件已存在；Native / 独立 DNA 尚未建立 | 从源节点11、4、6、7开始核对语义与原场景相对位置；具体历史适用性另外核验 |
| 弹壳/弹链处置路径 | 枪位中的输出与容纳关系 | 未建立 | 依据该枪位资料确认去向，区分缺失与不适用 |
| 控制、瞄准与外接联动 | 枪位与操作者/设备的关系 | 未建立 | 按手动或炮塔配置分别建图，不混用 |
| 材料、标记与服役状态 | 历史外观与变化记录 | 有两种程序材质候选 | 材料认定、铭牌、磨损与维修履历仍无对应实例证据 |

在机械原理层面，DNA 需要记住的是“供给—控制—运动—缓冲/复位—输出”的高层关系，以及各部件的作用；并非给每个外壳附一个材质就完成了机械对象。当前没有足够的语义与证据支持完整机构动画。

## 5. 父亲是谁，怎样进入飞机体系

“父亲”有两类，不能混为一条树：

**类型继承**：机械对象 → Browning M2 家族 → .50 航空型 → 有资料约束的配置。B-24 不是 M2 的型号父类。

**具体安装关系**：某架 B-24 历史实例 → 某个枪位/炮塔实例 → 对应支承/枪架组件 → 此枪实例 → 枪内语义子部件。瞄具、弹箱可能与枪互为枪位下的兄弟对象，再以连接、供给、控制等关系相连。

要在数字飞机中声明“已经装好”，至少要知道飞机型号/批次/日期、枪位身份、配置来源、共同参考架、连接锚点、与周围结构的空间关系、外接系统归属。当前这些条件没有闭合，所以只能保留“准备接入 B-24 的独立候选资产”，不能把枪拖进机舱就算装机正确。

若父链有可信世界锚点，才可沿链查询该枪的位置；若没有，世界位置和历史时间应继续未知，不能填零点或当前时间。美国空军国家博物馆也区分了 B-17/B-24 的手动活动枪位与动力炮塔，进一步说明必须按枪位建配置。[博物馆说明](https://www.nationalmuseum.af.mil/Visit/Museum-Exhibits/Fact-Sheets/Display/Article/1519669/gunners/)

## 6. 爆炸图怎么做才不会把缺口藏起来

下一版制作非功能性的展示分解视图：总装外观与展开视图可切换，显示部件名称、所属组、证据状态；回收展开后恢复同一总装状态。

先展示有依据的外部组成。未知内部件在清单中显式标缺，不用想象的几何填满内部。不能把7个渲染组直接拉开就命名为“完整爆炸图”。展示位移属于观察模式，不是历史对象真的散开，也不是机械拆卸路径。

制作次序：先修相机与后端已证实的表达错误 → 两枪同基准后端对照 → 核准组成表 → 外观展示分解图 → 继续补具体 B-24 枪位证据。整体验收与生产就绪仍保持 false。

# W10 — 表面与形态

依据 2026-09-08 与 Grace 阿妈的会议结论，将材质位置、候选对象状态和观察光线分开处理。

- 默认整枪单视图；两种候选表面、三种观察光线。载入核验原件自动进入相同中性材质对照。
- 材质地址使用命名域与固定数字参考坐标，网格属性仅为临时采样。连续余弦纹理使用屏幕导数低通，未改变几何。
- 状态由用户显式切换；没有自动老化。世界变换、历史日期保持未知。
- 重网格化映射、真实涂层更换沿革、世界内核接入、历史材质认定均未实现，不宣称会议接口全部落地。
- 形态规则与参数和 W09 字节一致。本轮不是新的几何拟合；W09 旧地址保持原样。

真实 GLB 已从本地 File API 核验载入。9 张截图检查涵盖默认外观、侧光金属、低照度、机匣/侧板/前环/整枪中性对照、整枪俯视轮廓及手机布局。程序检查：107 网格、90717 三角形，0 退化面，0 异常法线，0 浏览器错误；材质/观察切换前后几何哈希一致，错误上下文返回 unknown，错误原件被拒绝。

人工观察：默认表面可读；侧光下板层可分辨，低照度允许细节变暗；中性对照仍可见开口台阶和端面细节差异。整枪俯视护套孔与后握把轮廓仍不一致，整枪不能作为验收通过。B24 枪位、安装、瞄具、外接系统缺口继续保留。visualAcceptance=false，productionReady=false。

本轮未重复 W09 的全部数值拟合实验，未进行真实移动设备 GPU 性能测量。CPU 查询是命名域场求值，不验证给定点是否位于物体表面。

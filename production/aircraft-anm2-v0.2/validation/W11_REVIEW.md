# W11 — 总装、正常透视与对象关系

W11 将 2026-09-08 讨论落实为可交互外观审阅版。继承 W10 的机匣、盖板、侧板、前环、护套和侧面操作件规则；本轮只修整后端翼状件、握把端盖与圆筒端部外观，并新增原件已有的弹箱和弯曲弹带外观候选。原件布局不等于已认定的 B24 枪位安装。

- 立体展示使用正常透视，前后斜向均可查看。正侧、反侧、俯视、底面、前后端为固定正交测量视图；不使用镜像或负尺度补偿。对照的两边共用相机、比例与等尺寸画布。
- 总装对照包含原件 11 网格。完整原件入口保留全部 28 节点、13 网格，另外 2 个是单独摆放的样件，不计成第二套总装。
- 枪体 7 个外观组、供弹 2 个组、后端 4 个子对象，以及 58 个弹药展示实例各有记录，共 71 个对象和 3 个根记录。58 是本参考的可见实例数，不是武器容量或工作状态声明。
- typeOf、partOf、poseParent、carriedBy 分别定义。相对位置以数字参考架为上下文，无制造单位标定；世界姿态、历史时间与实体沿革未知。一个网格不自动等于一个实物部件，顶盖/侧板等保留区域或聚合候选标记。
- 展开为查看器偏移，可选择对象、读标签和坐标，也可收拢。不是拆卸动画、装配路径或可运行机构。
- 可导出 Object DNA JSON，明确为 0.1 项目交换草案；没有宣称跨 AI 通用标准。几何依赖固定版本可读规则，单独 JSON 不足以还原形状。每枚弹药和原始两个来源网格之间的精确对应未核验，只记录候选来源集合。
- 表面继续使用固定参考坐标。金黄色为展示候选材质；材质/灯光不替代同材质几何对照，不表示历史材质得到认定。

## 实际核验

从本地 File API 载入 6,548,040 字节、SHA-256 2d6a1f323018523db42d1fe54dcf1a26661f139548134835779933d61ab68c8b 的真实原件；错误文件被拒绝。源节点、矩阵与层级未改。页面不携带原件网格，不上传或缓存原件。

`tools/check_w11.cjs` 验证普通透视同长线段近端投影为远端两倍，固定正交投影等长；相机/候选对象矩阵行列式为正。71 条坐标链逐条与显示层级静止位置吻合；展开收拢前后完整生成几何哈希相同，导出 JSON 可读。未修改区域和 W10 在 1e-7 数字参考精度下逐顶点/索引一致。174 网格、105309 三角形，0 退化三角形、0 异常法线，0 浏览器错误；手机 390px 布局和对照画布比例检查通过。不是实机手机 GPU 性能结论。

`tools/measure_w11.cjs` / `.py` 在相同六方向正交画布上记录轮廓重叠、质心、面积、边界、孔洞与轮廓距离，同时从真实参考和生成体进行双向 3D 表面采样及截面检查。结果见 W11_MEASUREMENTS.json；生成和参考网格仅临时存在内存/管道，不保存产品网格。

## 明确保留的差异

后端的翼状外轮廓取代旧版框形，端盖与后侧圆筒的层次得到补充；握把曲线、侧操作件端部、圆筒朝前端面和翼状件厚度仍与原件不同。弹箱面板、箱盖/边缘与弹带连接片是简化解释；弹带弯曲大势相近，但细部、宽度及局部表面未达到同形。

可见外表面双向 P95：后端约 0.0104 / 0.0214，供弹约 0.0424 / 0.0424（数字参考单位）；预设门槛为 0.01，因此两区均未通过。各视图的轮廓 IoU 仅作诊断，不能取平均掩盖局部缺口。整枪与 B24 安装没有验收结论；visualAcceptance=false，productionReady=false。

缺口：枪管/护套语义细分、内部机构未实现；B24 具体型号、枪位、日期、安装、瞄具、外接与处置路径未知或适用性待定；真实材质和状态事件、世界内核接入、重网格化映射、跨系统交换未完成。

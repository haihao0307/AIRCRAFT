# W08 rejection and corrective gate

Date: 2026-09-07

## Decision

W08 is rejected as a visual-parity and measurement-method failure. Its immutable HTML remains only as a failed historical experiment. It must not be presented as the current review candidate, a successful reconstruction, or evidence that Object DNA geometry is progressing correctly.

The user's two actual loaded-reference screenshots are the decisive evidence. They show gross differences that should have caused an automatic and manual failure before delivery.

## Visible failures in the supplied screenshots

1. The reference and native objects do not share a valid mechanical registration. The receiver vertical position, barrel centerline, receiver front transition, and rear extent visibly diverge.
2. The native receiver is an over-simplified rectangular shell. It lacks the reference top-cover layering, side-plate contour, rear control/handle silhouette, openings, fastener families, and local transitions.
3. The barrel-to-receiver continuity is wrong. The native barrel root, front collar, exposed tube interval, perforated jacket start, jacket diameter, perforation pattern, and forward termination visibly disagree with the reference.
4. Major semantic components are absent. Feed-side exterior, top cover relationship, sight, disposal-side exterior openings, correct rear groups, B-24 installation layer, ammunition box, feed route, and mount remain missing.
5. The translucent overlay hides errors because the reference visually covers the native object. It does not provide a signed distance heat map, edge-only comparison, or region isolation.

## Root cause in W08

The reference view used one uniform scale derived from total X extent and one center translation. It did not register named mechanical datums such as barrel axis, muzzle plane, receiver front plane, receiver rear plane, or receiver top plane.

The MeasurementKernel sampled 64 planes in each object's own bounding-box-normalized coordinate. Therefore the same `t` value did not guarantee the same semantic or mechanical station in both objects.

Each section retained only minimum and maximum Y/Z. It discarded contour centroid, area, perimeter, loop count, holes, topology, orientation, component identity, and signed offset. A detailed receiver and a rectangular box can obtain a deceptively small envelope error.

The whole-gun mean was dominated by the long, thin barrel region. Large receiver errors were diluted across the full length. No semantic-region weighting or mandatory per-part pass existed.

No rejection threshold was implemented. The displayed maximum envelope error was allowed to appear as ordinary status. Missing components did not force failure.

The source GLB could not be loaded in CI, and the pilot record explicitly said the W08 actual-reference browser path had not been verified. Releasing W08 before an actual loaded-reference visual inspection made the user the first real visual QA. That process is unacceptable.

W08 also reused the W06 native geometry. Object DNA metadata and measurement UI were added without a corresponding geometry improvement. This was method scaffolding, not an improved Browning reconstruction, and it was presented too prominently.

## Mandatory correction before another user-facing version

1. Register reference and native twins using shared mechanical datums. At minimum: principal longitudinal axis, barrel centerline, muzzle plane, receiver-front plane, receiver-rear plane, and receiver-top plane. Total bounding-box alignment is prohibited as the review transform.
2. Build a semantic part correspondence table. Missing required parts are hard failures.
3. Measure every semantic region independently. Receiver, barrel root, jacket, muzzle, rear group, top cover, and side plates cannot be averaged into one whole-object score.
4. Replace envelope-only comparison with several independent gates: section contour centroid, area, perimeter, loop count, 2D contour distance, side/top/end silhouette overlap, 3D surface distance, anchor error, and part-presence completeness.
5. Use shared physical or normalized datum stations after registration. Each section must refer to the same mechanical location in both twins.
6. Add explicit thresholds and red failure states. Large local differences cannot be hidden by a small whole-object mean.
7. Review both twins in identical neutral material, fixed orthographic cameras, and edge-only or signed-distance modes. PBR is disabled during geometry approval.
8. Before delivery, load the actual reference and inspect at least side, reverse side, top, rear, axial, receiver close-up, barrel-root close-up, and jacket close-up. Save the review record. The user cannot be the first loaded-reference reviewer.
9. Rebuild geometry in a strict sequence: receiver datum shell, top-cover/plate layering, rear exterior groups, barrel-root/collar transition, jacket, forward termination, then remaining evidence-backed exterior components.
10. No new public HTML until the first rebuilt semantic region visibly improves against the reference and passes the new numerical gates.

## 附件实际支持什么

本轮解析两份辅助文件的材质槽与图片引用，临时解码并查看六张通道图片：7.62x54R 的 image 0/1/2，以及 AK 包的 image 8/9/10。看到的是作者制作的颜色变化、局部条带、细小斑驳及法线细节，不能由这些图片认定原物的金属成分、磨损过程或历史表面参数。图片可能包含UV空白和其他零件区域，不做全图平均后冒充真实材料测量。

文件的材质引用把 baseColor、metallicRoughness 和 normal 分开。AK 文件的若干材质还将同一张图用于遮蔽与金属/粗糙度。根据 Khronos glTF 2.0：底色 RGB 使用 sRGB，粗糙度取 G、金属度取 B，二者为线性数据；遮蔽使用 R。该解释来自外部格式规范。我们仅借鉴通道职责和可见层次，不复制图像、原UV或刻字。

Aircraft 主文件的一个材质与零图片状态延续本次实读结果。名义型号记录以官方馆藏 .50 CAL 为准，换算为12.7毫米；这没有验证原文件某颗弹丸的具体几何尺寸。不会采用用户口述的12.2作为正式规格。

## 新写的有限表面程序

surface_program.py 保存实体标签、主种子、种子版本、尺度比例及四个独立过程：finish_tint、surface_grain、micro_relief、film_variation。采用哈希派生的有限正弦频带，属于本轮新写的视觉近似；不声称等同 Blender/Adobe 的 Perlin 算法。

色差、粗糙度和微起伏有各自的频带。油膜覆盖是显式输入，默认零，未观察到的油污不会自动铺满枪体。它只通过独立的响应关系影响表层权重与粗糙度。螺丝和孔洞不在噪声程序中生成。

尺度为部件自身参照跨度的比例，尚未获得真实表面标定，不能称为微米级实测。固定高斯足迹对每条正弦频带作衰减。该衰减对线性正弦卷积可解释；非线性PBR和真实相机变焦的抗闪烁仍待目标渲染器验证。本轮没有实现动态屏幕导数、自动距离适配或手机优化。

同一程序可由 compile_blender 编译为节点。字段输入显式取部件Object坐标并除以参照跨度，细节随部件走。每个材质149个节点，本轮只作后台小范围验证，不能据此宣称适合实时网页或已经实现效率优势。

## 实际后台验证

headless_study.py 在独立容器里通过 Blender 4.5.0 --background 运行，DISPLAY为空，bpy.app.background为真。选取原件 Object_23/body_15 与 Object_25/sideplate_16 两个可见组，在相同相机、照明、AgX、128采样下比较微起伏关闭与开启。参考网格没有改造为新产品，两幅图只是材质研究证据。

研究前后主文件、顶点、UV、拓扑索引和对象世界变换校验一致。临时网格与图像数据已释放，未保存.blend或输出mesh/贴图。16项CPU检查通过，涵盖稳定种子、增添过程不扰动旧过程、通道隔离、合法参数、导数与足迹衰减。实际后台运行记录及像素差异在 reports 中，像素有变化不代表质量已通过。

近景中仍有渲染采样噪点，原件的侧板表面差异也尚未逐区解释。最初16采样不足以区分细节与采样噪声，已改为128采样复查；没有把那些采样颗粒当作材质成就。完整精细造型、历史材质标定、动画重建、浏览器与实体设备尚未完成。小妈复核未收到时保持 pending。

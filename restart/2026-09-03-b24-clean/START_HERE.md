## 新线第一原则

1. 先确定唯一整机基线及其真实文件身份。
2. 每个组件单独建立、检查、提交和等待用户批准。
3. 用户批准的组件保存实际文件、参数、依赖边界和验收证据，后续持续沿用。
4. 新改动只打开相关组件和真实依赖。
5. 用户视觉验收只交付可直接点击的在线三维 HTML 页面。
6. 在基础飞机、金属材质、3A 光照、草地跑道和完整任务流程获得批准以前，Weather Mother 保持暂停。

## 第一轮目标

1. 整机身份和原始机械动画正确。
2. 强金属机身质感与稳定的 3A 光照。
3. 无山体、无无关装饰的草地机场跑道。
4. 飞机与跑道方向一致，起飞、巡航、投弹、爆炸、返航、进近、着陆、滑回和关车连续运行。
5. 声音与镜头服务完整任务流程。

## 永久排除

1. Weapons Mother 代替整机生产线。
2. img2threejs 与 image2three 路线。
3. 程序化替代飞机。
4. 未经指令增加山体、建筑和远景装饰。
5. 用技术测试结果替代用户视觉批准。
6. 用压缩包、截图、制品卡或仓库文件页代替在线 HTML 视觉验收。

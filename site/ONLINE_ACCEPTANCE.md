# 第一版在线验收

打开网站后，先确认页面顶部明确显示“第一版测试涂装”。

在没有取到可下载权威 GLB 时，页面显示权威 Sketchfab 模型和第一版涂装板，且允许导入旧版内置 HTML。

在权威 GLB 通过大小和 SHA-256 校验后，页面自动进入 Three.js，支持：

- 原始材质、测试涂装、网格分类模式切换
- 左侧、右侧、机首、机尾、俯视、仰视、机鼻近景、尾部近景
- 机鼻图案与尾号显示开关
- 前后、左右、高低、尺寸、旋转校准
- 原始动画播放、暂停和时间轴
- 网格分类统计与 JSON 报告导出

当前版本不作为历史涂装定稿。下一版正确图片到位后再做正式 LiveryUV 与完整 PBR 烘焙。

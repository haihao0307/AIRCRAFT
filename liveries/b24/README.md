# B-24 livery line

Each approved B-24 historical aircraft receives one isolated directory here.

Required contents for a livery package:

- `livery.manifest.json`
- `historical-identity.json`
- `evidence/`
- `traces/`
- `uv/`
- `pbr/`
- `qa/`

A livery package may reference the authoritative model lock and an approved package below `knowledge/aircraft/b24/`. It may not contain a duplicate source GLB, flight runtime, task transcript, or unrelated aircraft identity.

The bilingual “80 DAYS” knowledge package lives at `knowledge/aircraft/b24/80-days/`. It is an upstream research source and does not activate or approve a B-24 livery.

No B-24 livery is active in the clean baseline.

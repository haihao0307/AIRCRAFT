# 程序噪波共享交接 V002

适用对象：小王、小李、飞机生产线以及后续材质负责人。

## 共享单位

共享库只保存算法、算子、输出规范、伪影与验证协议。每条生产线保存自己的尺度、方向、遮罩、材质通道与视觉批准。

## 小王，地貌生产线

1. Ridged、fBm、Domain Warping 可以生成实验性山脊与多尺度结构。
2. 真实 DEM、高程真值、水文和地质约束优先级最高。
3. 程序噪波可补充受控细节，不能替代真值或填补未知缺口后宣告真实。
4. Curl 可测试流向与侵蚀方向，仍需水文数据约束。

## 小李，建筑与材质生产线

1. Value、Simplex、Worley、Ridged 可以分别承担色彩变化、连续侵蚀、孔洞与剥落边缘候选。
2. 墙体层级、材料边界、施工逻辑、重力、潮湿与风化方向必须在噪波之前建立。
3. Wood/Marble 只在木材、石材或矿物身份成立时启用。
4. 任何裂纹、孔洞和剥落都要分层，禁止一套噪波覆盖全部墙面。

## 飞机生产线

1. Value 与 fBm 继续作为基础桥接层。
2. Ridged 当前只进入 V010 局部损伤实验。
3. Curl、Worley、Domain Warping 保持候选状态。
4. 结构权威、历史证据、左右舷涂装与保护组独立管理。
5. 局部实验通过不会自动批准整机。

## 版本纪律

1. 标题顺序证据与代码转录证据分开记录。
2. 项目编译通过与共享稳定批准分开记录。
3. WebGL 通过不能代替 WebGPU TSL 通过。
4. 视觉像素差不能代替用户视觉审批。
5. 每次交付保存哈希、浏览器、视角、参数和批准状态。

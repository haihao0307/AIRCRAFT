# B24 V010 Ridged 局部损伤实现说明

日期：2026-08-29

版本：`B24_NATIVE_REVIEW_V010_RIDGED_LOCAL_DAMAGE_EXPERIMENT_2026-08-29`

## 目标

本轮把 Ridged Noise 从知识母版的实验条目转成可复核的局部表面层。该层只处理机体易损边缘、短舱整流片、弹舱门、操纵面和少量外部细节。整机旧化继续由低强度 Value Noise 与四层 fBm 提供。

## 三重门控

1. 零件语义门控，按短舱整流片、弹舱门、舱门、操纵面、机体细节和普通蒙皮分配权重。
2. 几何过渡代理门控，只提供局部变化信号，不声明面板线权威。
3. 服役状态门控，服务预设保持克制，诊断预设放大响应以检查覆盖范围。

## 表面通道

1. Base Color，局部明暗和露底色调。
2. Roughness，局部粗糙度变化。
3. Metalness，只允许 Ridged 局部层少量提高。
4. Height，关闭。
5. Normal，关闭。

全局随机场与 fBm 不得提高 Metalness。

## 保护组

玻璃、螺旋桨、轮胎、起落架机构、动力机构、内部细节、旧武器和起落架路径默认权重为零。

QA 实测覆盖 330 个继承绘制件，其中 121 个属于保护组，保护组最大 Ridged 权重为 0。
